# smart-spatial-istanbul-health-access

**Which İstanbul mahalle (neighbourhoods) are underserved by hospitals and
clinics?** A spatial-accessibility case study that answers that question
twice — once with an explicitly written, rule-based query plan, once with a
plan generated by an LLM from the same question in natural language — and
compares the two.

Built on [Smart Spatial System](https://github.com/arazshah/smart_spatial_system),
consumed as a **pinned dependency** (`smart-spatial-system==0.3.0`). Its
source is never edited from here; bugs found in it are written up in
[`bugs/`](bugs/README.md). See [`CLAUDE.md`](CLAUDE.md) for why that rule
exists and what it means in practice.

Sibling study, same framework and same comparison metric, different city and
domain:
[`smart-spatial-vienna-accessibility`](https://github.com/arazshah/smart-spatial-vienna-accessibility).

## Method in one paragraph

Mahalle boundaries (`admin_level=10`) and hospital/clinic points
(`amenity=hospital|clinic`) come from OpenStreetMap via the Overpass API.
Everything metric happens in **EPSG:32635** (UTM 35N). The rule-based arm
reprojects each layer, computes nearest-facility distance (both
polygon-boundary and centroid), counts facilities per mahalle with
`zonal_statistics`, thresholds at 2000 m — reported at 1000 / 1500 / 2000 m
so the headline number is visibly a function of the cutoff — and dissolves
the underserved mahalle into contiguous regions. The LLM arm gets the same
question in natural language, *without* the threshold, CRS or operation
list, N=20 times, and its plans and outputs are compared to the rule-based
reference on three layers: plan structure, chosen parameters, and the
underserved set itself. Full method: [`paper/PLAN.md`](paper/PLAN.md);
metric definitions: [`paper/comparison_metric.md`](paper/comparison_metric.md).

## Getting started

```bash
pip install -r requirements.txt          # see the note in it about the pin's source
cp .env.example .env                     # only the LLM arm needs a key
python scripts/fetch_overpass.py         # needs a route to overpass-api.de
python scripts/overpass_to_geojson.py centers   data/raw/hospitals.json          data/raw/hospitals.geojson
python scripts/overpass_to_geojson.py relations data/raw/mahalle_boundaries.json data/raw/mahalle_boundaries.geojson
jupyter lab                              # then notebooks/01_... onward, in order
```

Blocked on Overpass? [`scripts/download_istanbul_data.md`](scripts/download_istanbul_data.md)
has two offline-friendly routes to the same files.
